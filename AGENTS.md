# AGENTS.md

This repository should use an absolutely minimal research style.

- Keep analyses and code simple, direct, and readable.
- Add code, dependencies, and directory structure only when they are needed to distinguish between the hypotheses in `README.md`.
- Prefer small functions and plain data over custom classes or frameworks.
- This is not production code. It is an initial investigation intended to clarify the physics.
- Complex code inhibits learning. Begin with scaling arguments and kinematic models before adding ice-flow complexity.
- State assumptions, units, boundary conditions, and the observational prediction of each model.
- Treat the steady models in `bradlipovsky/ice-wall` as a negative control. Do not reproduce or extend the Coulomb-rheology work unless a specific test requires it.
- Prefer simple continuum-mechanics language and define necessary technical terms.
- Separate observations, calculations, inferences, and speculative mechanisms.
- Follow `brad-lipovsky-academic-style-guide.md` for academic prose.
- Save notebooks with figures and outputs intact, then commit and push them to GitHub.
